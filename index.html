T-Symphony Fix

Play sound from your TCL TV speakers and any eARC soundbar at the same time, and line them up with an adjustable speaker delay.

What it does

  • Turns on the TV's built-in T-Symphony mode (TV speakers + soundbar together) for any eARC soundbar, not only TCL-certified ones.
  • Delays the TV speakers so they stay in sync with the soundbar. Default 50 ms, adjustable with the remote.
  • Turns it back on when the TV resets it (soundbar reconnect, screen off/on).

Install (one time, needs a computer with adb)

  1. On the TV: Settings → System (or Device Preferences) → About, press Build 7 times. Then open Developer options and enable USB debugging / network debugging. Note the TV's IP address.
  2. On the computer, connect and allow the prompt on the TV: 
    adb connect TV_IP:5555
  3. Install the app: 
    adb install tsymfix.apk
  4. Allow it to switch T-Symphony on (required): 
    adb shell pm grant local.tsymfix android.permission.WRITE_SECURE_SETTINGS
  5. Open T-Symphony Fix from the TV's app list.

Use

  • −10 / −5 / +5 / +10 ms: if the TV speakers sound ahead of the soundbar, increase the delay; if they lag, decrease it.
  • Service: on / off: off returns the TV to stock behaviour (soundbar only, no delay).
  • Language: English, Ukrainian, Russian.

Notes

  • After a full reboot, if the TV speakers stay silent, open the app once. Some TVs block apps from starting on boot.
  • To uninstall, set Service: off first, then adb uninstall local.tsymfix.
